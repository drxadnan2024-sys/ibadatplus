# Hadith Dataset Sources & Authentication Details

All Hadith texts in **Ibadat Plus** are strictly sourced from verified, authentic open-access public domain Hadith databases. No Hadith is AI-generated.

### Sources:
1. **Sahih al-Bukhari (صحيح البخاري)**:
   - Primary Repository: Sunnah.com Open Dataset (`https://sunnah.com/bukhari`)
   - API / JSON Dataset: `fawazahmed0/hadith-api` (Verified public domain Hadith text & translations)
   - Compiler: Imam Muhammad al-Bukhari (194–256 AH / 810–870 CE)

2. **Sahih Muslim (صحيح مسلم)**:
   - Primary Repository: Sunnah.com Open Dataset (`https://sunnah.com/muslim`)
   - API / JSON Dataset: `fawazahmed0/hadith-api` (Verified public domain Hadith text & translations)
   - Compiler: Imam Muslim ibn al-Hajjaj (204–261 AH / 815–875 CE)

### Fields Included:
- **Arabic Text (النص العربي)**: Fully vocalized Tashkeel / I'rab authentic matn
- **Urdu Translation (اردو ترجمہ)**: Verified authentic translation
- **English Translation**: Standard accepted Sahih International / Muhsin Khan translations
- **Reference & Number**: Official Sunnah.com numbering and classical book numbering
